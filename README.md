# College Basketball Coach Simulator — Modular Deep Engine

Run:
1. `pip install -r requirements.txt`
2. `streamlit run app.py`

Modules:
- models.py — game data models
- teams.py — real-team starter data, roster/recruit generation
- simulation.py — games and schedules
- recruiting.py — recruiting, NIL and transfer portal
- career.py — coach prestige, job tiers, contracts and carousel
- save_system.py — versioned migration/repair
- app.py — Streamlit interface

This build is designed as a clean foundation for further dynasty systems.
